## التشغيل محليًا

المتطلبات: Node 22+، PostgreSQL 16 (محلي أو Neon).

```bash
cp .env.example .env          # عدّل القيم (خصوصًا OWNER_* و SESSION_SECRET)
npm install
npx prisma migrate deploy     # إنشاء الجداول
npm run db:seed               # 56 منتج، 33 أسبوع، 5 محركات، البنك 20,000، حساب المالك
npm run dev                   # http://localhost:3000
```

## النشر (Vercel + Neon) — من الجوال

1. **Neon:** انسخ رابطين من صفحة Connection Details: الـ **pooled** والـ **direct** (من غير `-pooler`).
2. **Vercel → Add New → Project →** `capoog/saif`، وضيف Environment Variables:

   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | رابط Neon الـ pooled |
   | `DIRECT_URL` | رابط Neon المباشر |
   | `SESSION_SECRET` | نص عشوائي 32 حرف+ |
   | `OWNER_EMAIL` | إيميل الدخول |
   | `OWNER_PASSWORD` | كلمة مرور (8 حروف+) |

3. Deploy. أمر `vercel-build` بيعمل تلقائيًا: إنشاء/تحديث الجداول ← البيانات الأولية ← البناء.
   البيانات الأولية آمنة مع كل نشر: مش بتكرر حاجة، ومش بتغيّر باسورد المالك لو موجود.
4. بعد أول دخول: فعّل التحقق الثنائي من الإعدادات.

النسخ الاحتياطي اليومي: `.github/workflows/backup.yml` محتاج GitHub secrets `DATABASE_URL_BACKUP` (الرابط المباشر) و `BACKUP_PASSPHRASE` — نسخة مشفّرة AES-256 تتحفظ 30 يوم، بالإضافة لـ point-in-time restore في Neon.

### القرار المعماري الأساسي: دفتر قيود مزدوج

كل عملية مالية (بيع، شراء، مصروف، عربون، مرتجع…) بتسجل قيد متوازن (مدين = دائن) على دليل حسابات ثابت
(`src/server/chart.ts`). رأس المال بيتحسب من أرصدة الدفتر في دالة واحدة (`src/domain/capital.ts`):

```
رأس المال = النقد + المخزون بالتكلفة + الذمم المضمونة (≤ 30 يوم)
          − الالتزامات (موردين، مستقلين، عرابين، قروض)
          − ضريبة محصّلة غير مسددة − مخصص الزكاة
          − رأس مال الشريك (لا يُحسب في الهدف)
```

- **العربون**: كل مدفوعات الطلب على حساب "العملاء" لنفس الطلب. قبل التسليم رصيده دائن = التزام. عند التسليم بيتسجل الإيراد والضريبة وتكلفة FIFO.
- **الضريبة المحصّلة**: حساب التزام منفصل، مش إيراد أبدًا.
- **الحذف**: قيد عكسي + `deletedAt`. الدفتر لا يُعدّل أبدًا، وكل عملية مالية في `AuditLog`.

## قرارات اتاخدت باقتراحاتي (قابلة للتغيير)

| القرار | المطبّق |
|---|---|
| ألوان الحالة | أخضر > +3% · أزرق ±3% · أصفر حتى −25% · أحمر أقل من −25% (من الإعدادات) |
| الضريبة | غير مسجل افتراضيًا → الطلبات بدون ضريبة، وتتفعّل من الإعدادات |
| الزكاة | 2.5% ÷ 12 شهريًا على رأس المال، تتحسب مرة لكل شهر عند الإغلاق |
| رأس المال المستخدم لكل محرك | مخزونه بالتكلفة + ذممه المضمونة |
| هدف اليوم في لوحة التحكم | خطي بين بداية ونهاية هدف الأسبوع، والإغلاق بيقارن بهدف نهاية الأسبوع |
| الدفع عند الاستلام | ذمة لحد ما تسجّل التحصيل من شاشة الطلب |
| الدخول | جلسات في القاعدة + bcrypt + TOTP (بدون Auth.js — أبسط وتحت سيطرتنا) |
| الرسم | مقياس لوغاريتمي لأن المسار أسّي |
